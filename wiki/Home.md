Welcome to the **AWE_Forge** wiki. This is the comprehensive documentation for the most powerful single-page serverless web application ever built.

## 🏗️ Architecture Overview

AWE_Forge is a **100KB+ single HTML file** that implements a complete web platform with:

- **Hash-based routing** — 17+ pages navigable via `#page` URLs
- **10-language i18n system** — Full translations for every UI string
- **Dark/Light theme engine** — CSS custom properties with instant switching
- **localStorage persistence** — Settings, history, favorites survive refreshes
- **Zero dependencies** — Pure HTML/CSS/JS, no frameworks, no build step
- **GitHub Pages hosted** — Deployed at [ararat33.github.io/Zaropl](https://ararat33.github.io/Zaropl)
