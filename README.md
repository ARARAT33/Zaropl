## 🏗️ What is AWE_Forge?

AWE_Forge is a massive serverless web platform contained in a single HTML file. No frameworks, no backend, no build step — just pure HTML/CSS/JS.

### Features
- 🌍 **10 languages** — EN, HY, RU, ZH, ES, FR, DE, AR, JA, PT
- 🎮 **5 web games** — Incremental/idle games with prestige systems
- 🔧 **22 built-in tools** — Encoders, generators, formatters, analyzers
- ⚡ **Nexus Terminal** — 7-layer quantum state engine
- 🧪 **Particle simulator** — Interactive physics with click-to-spawn
- 💻 **Code sandbox** — Live HTML/CSS/JS editor
- 📝 **Blog integration** — RSS feed from blogma-wa.blogspot.com
- 📊 **Dashboard** — localStorage-based history and favorites
- 🎨 **Dark/Light theme** — CSS custom properties, instant toggle
- 📱 **Fully responsive** — Mobile, tablet, desktop
